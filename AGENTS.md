## AI commit attribution — repository owner only

- NEVER add `Co-Authored-By:`, `Generated with`, `Generated by`, `Signed-off-by` bot trailers, or any AI/tool attribution line to commit messages, pull request titles, pull request bodies, or release notes.
- ALWAYS commit with the repository owner's configured git identity (`git config user.name` / `git config user.email`). Never set a bot or agent identity for commits, and never override `GIT_AUTHOR_*` / `GIT_COMMITTER_*` variables.
- This repository may enforce this rule mechanically via git hooks (`.githooks/`). If a commit, tag or ref update is refused by those hooks, fix the identity or message — do NOT bypass it with `--no-verify`, plumbing commands (`commit-tree`, `update-ref`), or by editing git config. If a hook itself is broken, report it to the user instead of disabling it.
- Keep Conventional Commits style and write commit messages in the project's language.
- This rule applies to every AI assistant or coding agent operating in this repository, regardless of vendor.
